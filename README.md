# Random Generator Project

## About The Project
This is a desktop application designed to generate random values. Built with **C#** and **Windows Forms**, it provides a simple and interactive user interface for generating random outputs.

## Technical Details
This project uses the following technologies:
* **Programming Language:** C#
* **Framework:** .NET Framework 4.7.2
* **User Interface:** Windows Forms (WinForms)
* **Environment:** Visual Studio

## How It Works (Under the Hood)
* **The UI (User Interface):** The application screen is built using `Form1.Designer.cs`, which contains the layout for buttons and display areas.
* **Application Logic:** The core functionality is written inside `Form1.cs`.
    * The application relies on C# logic to generate random values.
    * When the user interacts with the app (e.g., clicks a button), an **event handler** is triggered.
    * The generated result is then displayed on the screen instantly.

## How to Run the App
1. Open the project folder in **Visual Studio**.
2. Double-click on the `Random Generato project.csproj` or the `.slnx` file to open the solution.
3. Press the **Start** button (or `F5` on your keyboard) to build and run the application.
